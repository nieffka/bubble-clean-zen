## ⚙️ How to Install

1. Install [Sine](https://github.com/CosmoCreeper/Sine).
2. Go to Settings → Sine Mods.
3. Open Sine's settings and enable installing JS from unofficial sources.
4. Paste this into custom mod input: `nieffka/bubble-clean-zen` and click **Install**.
5. Restart Zen Browser or open `about:support` and click **Clear startup cache**.

#### 💠 Optional Tweak
Go to `about:config` and set:

| Name                                                  | Set    | Description                                      |
| ----------------------------------------------------- | ------ | ------------------------------------------------ |
| `zen.theme.content-element-separation`                | `6`    | Thinner web view borders                         |
| `zen.view.enable-loading-indicator`                   | `false`| Disable Zen native loading indicator             |
| `browser.tabs.allow_transparent_browser`              | `true` | Allow transparency                               |
| `widget.windows.mica`                                 | `true` | Allow transparency                               |

Get real backdrop filter transparency with this 3rd party software:

| Type       | Details            | Links                                                                                      |
| ---------- | ------------------ | ------------------------------------------------------------------------------------------ |
| Software   | `MicaForEveryone`  | [MicaForEveryone](https://github.com/MicaForEveryone/MicaForEveryone)                      |
| Software   | `DWMBlurGlass`     | [DWMBlurGlass](https://github.com/Maplespe/DWMBlurGlass)                                   |
